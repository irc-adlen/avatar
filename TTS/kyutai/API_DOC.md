# API Documentation

## Overview

This API provides an interface for a low-latency, real-time voice assistant tailored for CPE Lyon engineering projects. It orchestrates communication between a Large Language Model (**Ollama**) and a Neural Text-to-Speech engine (**Moshi TTS**).

The system utilizes a **Split Architecture (Producer/Consumer)** pattern to decouple text generation from audio streaming.

## System Architecture

1. **Output Channel (WebSocket):** Clients (Avatars, Frontends) connect here to receive audio and synchronization timestamps.
2. **Input Channel (HTTP POST):** Clients send text prompts here to trigger the assistant.

## API Reference

### 1. Audio Output Stream

**Endpoint:** `ws://localhost:8000/stream/audio`

**Protocol:** WebSocket

This endpoint streams audio data and metadata. **A client must be connected to this endpoint before sending any chat requests.**

#### Received Message Formats

Consumers must switch logic based on the `type` field of the received JSON.

**A. Audio Data (`type: "audio"`)**
Contains a chunk of raw PCM audio.

```json
{
  "type": "audio",
  "data": "UklGRCQAAAB...",    // Base64 encoded Raw PCM (Float32)
  "sample_rate": 24000       // Sample rate in Hz
}

```

* **Decoding:** Decode Base64  Bytes  Float32 Array.
* **Format:** Mono, 24kHz.

**B. Synchronization Metadata (`type: "meta"`)**
Contains alignment information generated by the "Delayed Streams" technique. This allows you to synchronize lip-syncing or subtitles.


```json
{
  "type": "meta",
  "content": {
    "type": "Text",     // Or "TextToken" depending on server version
    "start_s": 0.52,           // Start time in seconds
    "stop_s": 0.85,             // End time in seconds
    "text": "Lyon"           // The word/token being pronounced
  }
}

```

**C. Error (`type: "error"`)**
Sent when an upstream service fails.

```json
{
  "type": "error",
  "message": "Connection to Moshi server lost."
}

```

### 2. Chat Trigger

**Endpoint:** `http://localhost:8000/chat`

**Method:** `POST`

**Content-Type:** `application/json`

Initiates the generation pipeline.

#### Request Body

```json
{
  "prompt": "Explain Quantum Mechanics simply.",
  "voice": "default_voice.wav",       // Optional. Default: "default_voice.wav"
  "system": "You are a physics professor."  // Optional. Overrides default system prompt.
}

```

#### Response

```json
{
  "status": "processing_started"
}

```

## Deployment Instructions

### Prerequisites

Ensure the following services are running locally:

1. **Moshi Server** (Port 8080):
```bash
moshi-server worker --config config-tts-local.toml

```


2. **Ollama** (Port 11434):
```bash
ollama serve

```



### Starting the API

1. Install dependencies:
```bash
pip install fastapi uvicorn websockets msgpack aiohttp

```


2. Run the server:
```bash
python api_agent_cpe.py

```



The API is now ready to accept connections on port `8000`.
