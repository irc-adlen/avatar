# API Documentation

## Overview

This API acts as the **central nervous system** of the robot. It unifies:

- **LLM Brain:** Mistral-Nemo (running on vLLM).
- **Speech:** Kuytai TTS (with stream capabilities).
- **Memory:** MongoDB (Persistent conversation history).
- **Knowledge:** RAG (PDF Analysis).

## Base URL

`http://<SERVER_IP>:8000`

---

## 1. The Chat Endpoint (`POST /chat`)

This is the **single entry point** for everything (Face Recognition commands and User Dialogue).

### Request Format

```json
{
  "text": "String. The input text or system command.",
  "session_id": "String. Unique ID for the current interaction.",
  "user_name": "String (Optional). Name of the user if known."
}
```

### Response Format

```json
{
  "text": "String. The text response generated by the AI.",
  "audio": "String. Base64 encoded WAV audio file (ready to play).",
  "extra_data": {
    "name": "Michel",
    "filiere": "Chemistry"
  } // Null unless data was extracted
}
```

---

## 2. Usage Scenarios

### Scenario A: Face Recognition (Known User)

**Trigger:** The camera identifies "Michel".
**Request:**

```json
{
  "text": "[system] Dis bonjour à Michel",
  "session_id": "session_123"
}
```

**Response:**

- `text`: "Bonjour Michel, ravi de vous revoir..."
- `audio`: [Base64 Audio of the greeting]

### Scenario B: Face Recognition (Unknown User)

**Trigger:** The camera detects a new face.
**Request:**

```json
{
  "text": "[system] Demande le prenom de la personne",
  "session_id": "session_456"
}
```

**Response:**

- `text`: "Bonjour, je ne vous reconnais pas. Quel est votre prénom ?"
- `audio`: [Base64 Audio]

### Scenario C: User Replies to Name Question

**Trigger:** User says "Je m'appelle Sarah".
**Request:**

```json
{
  "text": "Je m'appelle Sarah",
  "session_id": "session_456"
  // MUST match the session_id of Scenario B to trigger extraction logic
}
```

**Response:**

- `text`: "Enchanté Sarah. J'ai bien noté vos informations."
- `extra_data`: `{"name": "Sarah"}` -> **Use this to update your database.**

### Scenario D: Standard Question (RAG)

**Trigger:** User asks a question about the school.
**Request:**

```json
{
  "text": "Quelles sont les majeures en chimie ?",
  "session_id": "session_123"
}
```

**Response:**

- `text`: "Les majeures sont Chimie Analytique et Génie des Procédés..." (Based on PDFs)
- `audio`: [Base64 Audio]

---

## 3. Deployment Notes

- **PDFs:** Place all school PDF documents in the `/data` folder.
- **Voice Cloning:** Place a 5-second WAV file of the desired voice named `default_voice.wav` in the root folder.
- **GPU Usage:** The system requires **2x Nvidia GPUs**. It splits the LLM across both and places the TTS on GPU 0.
