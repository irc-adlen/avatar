# Add new detecable person

When the program is started and a new person comes. The assistant should ask for the person to present themself.
When it's done, a picture is taken and the person can now be recognized.

# Docker

All the project can be run using Docker.
It currently contains two Dockers.
This script is currently planned to be run with the root [docker compose](/docker-compose.yml). 

### run the Dockers

```bash
docker compose up
```
